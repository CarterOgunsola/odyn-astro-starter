# Decisions

The reasoning behind the starter, one record per dependency and per convention. Six months from now "why is this here" gets an answer instead of a guess, and a project born from the starter carries its own history at handover.

Rules:

- One record per dependency and per convention. A removal gets a record too, in the same shape, so the reversal reads as clearly as the choice.
- Numbers are never reused. A superseded record stays put with its status changed and a pointer to the record that replaced it.
- Every record carries a date and a status (proposed, accepted, deprecated or superseded).
- Decisions here are never final. When a project deletes something without noticing, that is evidence, and the record should change.

Start a new record by copying 000-template.md.
