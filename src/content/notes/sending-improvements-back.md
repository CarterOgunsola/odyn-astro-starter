---
title: "Sending improvements back"
description: "The reverse flow is a pull request, in the same session."
date: 2026-09-04
---

A project that improves a file from this starter opens a pull request here in the same session, or logs the change in its own `docs/upstream.md` for later.

The starter only changes by graduation from a real project. The second project decides what enters, not the first.
